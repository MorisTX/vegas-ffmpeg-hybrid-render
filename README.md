# VEGAS FFmpeg Hybrid Render

A VEGAS Pro C# script that renders complex timeline ranges in VEGAS, processes simple ranges with FFmpeg, and assembles the final MP4 with audio.

[История изменений](CHANGELOG.md)

`AnalyzeSelectedRangeForHybrid.cs` - скрипт для VEGAS Pro, который рендерит выделенный диапазон таймлайна через гибридный пайплайн:

- сложные участки рендерятся самим VEGAS Pro
- простые видеофрагменты рендерятся через FFmpeg
- все части собираются в итоговый MP4
- звук рендерится из VEGAS и добавляется в финальный файл

Это может ускорить длинный рендер, если только часть таймлайна требует полноценной обработки VEGAS.

## Требования

- VEGAS Pro с поддержкой C#-скриптов
- `ffmpeg` и `ffprobe` в `PATH`
- сохраненный VEGAS-проект
- выделенный непустой диапазон на таймлайне

## Использование

1. Скопируйте `AnalyzeSelectedRangeForHybrid.cs` в папку скриптов VEGAS или запустите через `Tools > Scripting > Run Script`.
2. Откройте и сохраните `.veg`-проект.
3. Выделите диапазон таймлайна, который нужно отрендерить.
4. Запустите скрипт.
5. Выберите шаблоны видео и звука, **Temporary files folder** и **Final output folder**.
6. Для обычного запуска или продолжения выберите **Auto / continue from detected outputs** и нажмите **Run**.

Скрипт проверяет готовые файлы и пропускает пройденные этапы. Чтобы повторить конкретный этап, выберите его в **Start stage**: более ранние этапы должны пройти проверку. Для продолжения после перезапуска используйте тот же проект, диапазон и временную папку.

Если упадёт сборка видео или финального MP4, нажмите **Retry**, выберите новую папку, и скрипт повторит только этот этап с готовыми входными файлами. Недописанный MP4 этой попытки удаляется при обработанном сбое; уже готовый выходной файл сохраняется до успешной замены.
